# AI MultiModal Assistant 🤖

A comprehensive AI-powered assistant that combines text chat, voice interaction, and image generation capabilities in a single, beautiful space-themed Streamlit interface.

## ✨ Features

### 💬 Text Chat Mode
- Real-time AI conversations with Meta Llama 3.2 3B
- Full conversation history
- Context-aware responses

### 🎤 Voice Mode
- Speech-to-text input using Google Speech Recognition
- Text-to-speech output using gTTS
- Voice conversation history

### 🎨 Image Generator
- Text-to-image generation using FLUX.1-schnell
- 10 artistic style presets (Realistic, Anime, Digital Art, Watercolor, etc.)
- Download generated images

## 🌌 Space Theme UI
- Animated starfield background
- Neon glow effects and cosmic gradients
- Orbitron font for futuristic feel
- Dark theme with purple/blue color scheme

## 🚀 Quick Start

1. Enter your message in the Text Chat tab
2. Or click the microphone in Voice Mode to speak
3. Or describe an image in the Image Generator tab
